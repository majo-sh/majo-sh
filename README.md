## De una fiesta real a un SaaS

Fiestas empezó como una solución para una celebración familiar. La primera versión se usó en un evento con aproximadamente **30 participantes** y reunió **163 recuerdos** entre fotos y videos.

La respuesta de los invitados convirtió ese experimento en algo más grande: rediseñé la arquitectura para soportar múltiples eventos, marcas y organizadores sin perder la experiencia sencilla del QR.

## Cómo pienso cuando construyo

```ts
const ship = async (idea: Idea) => {
  const problem = await understand(idea);
  const prototype = await buildSmall(problem);
  const evidence = await testWithPeople(prototype);

  return evidence.isUseful ? turnIntoProduct(prototype) : learn(evidence);
};
```

No me interesa agregar IA porque esté de moda. Me interesa usarla cuando reduce trabajo, organiza información o mejora una decisión sin quitarle el control a la persona.
